# Raycast Extensions

Personal [Raycast](https://raycast.com) extensions.

| Extension | Description |
| --- | --- |
| [azure-resources](azure-resources) | Browse and open Azure resource groups and resources |
| [spotify-add-to-playlist](spotify-add-to-playlist) | Add the currently playing Spotify track to one of your playlists |
| [vivenu](vivenu) | Show tickets, create free tickets and view an event dashboard for vivenu |

## Development

Each extension is a standalone Raycast project:

```sh
cd <extension>
npm install
npm run dev
```
